# 🏨 Hotel Management System — Java + Swing + MySQL

A complete desktop-based Hotel Management System built using **Java (Swing)** for the GUI and **MySQL Workbench** as the backend database.
This system helps hotel staff manage customers, rooms, bookings, billing, and more.

## 🚀 Features

- 🧑‍💼 Admin and staff login system
- 🏠 Room booking and availability management
- 📋 Customer details entry and management
- 💵 Billing and invoice generation
- 📦 Check-in & Check-out system
- 🧾 Real-time data storage using MySQL

## 🛠 Tech Stack

- **Frontend:** Java Swing (GUI)
- **Backend:** MySQL Workbench (Database)
- **IDE:** IntelliJ IDEA / Eclipse
- **Connectivity:** JDBC (Java Database Connectivity)
